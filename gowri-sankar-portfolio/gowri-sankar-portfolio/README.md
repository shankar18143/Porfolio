# Gowri Sankar Guggilla — Portfolio

Personal portfolio for AI/ML development, Generative AI, agentic systems, and data engineering.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Structure
- `index.html` — portfolio content and project descriptions
- `css/style.css` — responsive visual design
- `js/script.js` — mobile navigation, active section navigation, reveal effects
- `images/projects/` — add project screenshots here

## Before publishing
- Verify all contact and social links.
- Add a profile photo and project screenshots if desired.
- Add public repository/demo links to the relevant project cards when available.
- Confirm the CGPA and project status details are current.

Built with HTML, CSS, and vanilla JavaScript.
