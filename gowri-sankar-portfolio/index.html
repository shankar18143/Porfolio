01 / AI ASSISTANT↗

Personal AI system · Modular architecture

SAM — Smart AI Assistant

A modular personal AI assistant designed to bring conversational intelligence, voice interaction, and extensible capabilities into one system.

What it does

SAM is organized into UI, Core, Agents, Security, Training, Data, and Models modules. It combines text interaction with speech output and supports both local and cloud-based language-model workflows.

Architecture & implementation

  • Uses Ollama for local LLM experimentation and Hugging Face inference for cloud model access.
  • Uses pyttsx3 for offline text-to-speech, supporting voice output without depending on a paid TTS service.
  • Explores custom tokenizer and model-training workflows using PyTorch, Hugging Face Tokenizers, and JSON/JSONL datasets.
  • Separates agents, security, data, and model logic to keep the assistant extensible.

Problem it addresses

Creates a personal assistant foundation that can run with local models, reduce reliance on paid APIs, and grow through independent modules.

Python · Ollama · Hugging Face · PyTorch · Tokenizers · pyttsx3

03 / AGENTIC AI↗

Apexon / GenAI Analytics · Multi-agent workflow

ProjectOps AI

An AI-powered project management and analytics solution designed to help teams understand project health, surface risks, and act on dependencies.

Multi-agent architecture

  • Project Analysis Agent: interprets project information and summarizes progress.
  • Risk Analysis Agent: identifies potential delivery risks and concerns.
  • Dependency Analysis Agent: examines task relationships and blockers.
  • Recommendation Agent: converts findings into practical next-step recommendations.

Orchestration & validation

Agents are coordinated using LangGraph, with Ollama providing the LLM layer. A harness-validation step checks agent outputs before they are used downstream.

Problem it addresses

Helps project managers move beyond manual status tracking by combining progress analysis, risk identification, dependency reasoning, and recommendations in one workflow.

Python · LangGraph · Ollama · LLMs · Multi-agent systems · Harness validation
04 / EDUCATIONAL AI↗

AI learning assistant · In development

Chitti — AI Student Assistant

An AI-powered learning companion designed to make educational content easier to understand for Telugu-speaking and regional-language learners.

Core capabilities

  • Telugu and bilingual question answering with simple-explanation mode.
  • Voice-based interaction to make learning more accessible.
  • OCR-based extraction from textbook and study-material images.
  • Student-friendly explanations and a learning-focused interface.

Technical approach

React and Tailwind CSS form the frontend, with a Python FastAPI backend. The project explores OCR, LLM integration, and lightweight memory using SQLite/JSON.

Goal

Reduce language and comprehension barriers by helping students ask questions naturally and understand difficult topics in accessible language.

React · Tailwind CSS · FastAPI · Python · OCR · LLMs · SQLite
